## 近期更新（23）

- [阮一峰的网络日志](https://www.ruanyifeng.com/blog/archives.html) — 经典必看，每周更新。无聊是看新闻、还是学习、还是拓展眼界，都是能其中获取到乐趣的。还有很多网友的每周留言。这就是 blog 的含金量。（推荐：★★★★★）
- [Josh W. Comeau](https://www.joshwcomeau.com/) — John blog 更像是一个课程网站，每一篇文章都书写的很好，每次阅读都能吸收到新的东西。网站设计也恰到好处，工整、有趣。（推荐：★★★★★）
- [nanda](https://www.nan.fyi/) — 设计大师，nanda 。页面只用灰色加线条，都让我觉得叹为观止，内容不多，每篇都精雕细琢。跟 Josh 一样，属于技术网站，但它的教程引导更加出神入化，可称为程序艺术家。（推荐：★★★★★）
- [Innei 静かな森](https://innei.in/) — 网站还行，是典型的那种某个时代的产物，我不太get。但是内容活跃，并且他好像很火？但我没找出他为什么火。项目还是挺多的。（推荐：★★★☆☆）
- [BlogFinder](https://bf.zzxworld.com/) — 一个 blog 收集网站，可以查阅有哪些 blog，也可以直接看最近谁更新了什么（推荐：★★★☆☆）
- [Tonsky](https://tonsky.me/) — 一个过去的国外大神，忘了是什么时候发现它的，blog 依旧时不时更新。就是现在 blog 太刺眼了，不知道是不是故意的。（推荐：★★★☆☆）
- [Chrome Blog](https://web.dev/blog?hl=zh-cn) — 技术团队 blog，咨询、动态、故事。我觉得页面感受还不错。（推荐：★★★★☆）
- [Brian Lovin](https://brianlovin.com/) — 早期外国大神，在 Github,Facebook 工作过，现在在notion，资历老、项目多。blog 写成了 Dashboard 风格，蛮奇特的，但是 blog 并不多。（推荐：★★★★☆）
- [Niracler 的博物志](https://niracler.com/) — 小透明，偶尔更新一篇blog。但是网站风格还是有特点的，可作为设计 blog 时的参考。（推荐：★★☆☆☆）
- [阿猫的博客](https://ameow.xyz/) — 可爱的网站，一直在更新他的猫鱼周刊。（推荐：★★★☆☆）
- [pseudoyu](https://www.pseudoyu.com/) — 区块链开发者，在 Monad 区块链倒腾了一段时间。网站长得跟 Anthony 一模一样。嘴上一直念叨着他的学姐老婆。应该也挺厉害的。（推荐：★★★☆☆）
- [微尔微](https://www.vio.vin/) — 23 年新晋散修，如他所说，一天倒腾一些奇怪的东西。应该是以后端为主，喜欢完一些硬件。静森系 blog，25年 blog 稳定输出。（推荐：★★☆☆☆）
- [搬砖日记](https://banzhuanriji.com/) — 白底黑字。但是打理得挺好的。应该是 Andriod 开发者，24 年开始分享各种探索。摸不清根底。（推荐：★★☆☆☆）
- [猫普的精神世界](https://maplezz.com/) — 通过 issue 发现的另外一个开源的，也是这几天开源的，好巧。液态玻璃感设计，是有这种感觉，挺好的，就是有的花。我还是挺喜欢的。内容从 25年开始。（推荐：★★★☆☆）
- [手里有只毛毛虫](https://www.krjojo.com/) — 网站很舒服，一位六边形战士的独立开发者。文章目录能一眼看完就好了，想翻点想看的比较不容易。（推荐：★★★★☆）
- [Honesty](https://blog.hehouhui.cn/) — 折腾 blog 的后端，是个后端学习的榜样，折腾了这么多年。网站弄得还挺好的，就是加载内容有点慢。（推荐：★★★☆☆）
- [十玖八柒](https://blog.ahzoo.cn/) — Z次元，后端开发，记录了很多后端研究。但折腾前端和 blog 还不少。把 blog 打理得有自己独特得舒适，实属难得（推荐：★★★☆☆）
- [纸鹿摸鱼处](https://blog.zhilu.site/) — 棒棒的开源 blog 主，今天蹭了蹭他群友，🤣，给他多加一分🤣🤣🤣。（推荐：★★★★☆）
- [23朵毒蘑菇](https://blog.dumogu.top/) — 前端开发，页面小巧，结构简单，寻常记录（推荐：★★★☆☆）
- [陈梓聪](https://leoku.dev/zh/me) — v2ex 发现的人，并不发blog，但是个人网站很好看，一眼过去，很难不称赞。开源的 V2EX_Polish 确实很好用。（推荐：★★★★☆）
- [haoqi.design](https://haoqi.design/) — 设计的很棒的个人网站（推荐：★★★★★）
- [Bakai](https://www.bakai.me/) — 还在就读的设计师，它的 Lab 还是值得看看的（推荐：★★★☆☆）
- [Yu Yoshimuta](https://yuyoshimuta.com/) — 几何体设计的语言艺术（推荐：★★★★☆）

## 长期失联（16）

- [Enji Kusnadi](https://enji.dev/) — 第一个在设计样式上惊艳我的人，那时每逢推荐别人blog，我都会提这么一嘴。但这个不算她的blog 网站，只算它的线上简历，没有持续的内容，比较可惜。（推荐：★★★☆☆）
- [Emil Kowalski](https://emilkowal.ski/) — Blog 就干脆"不设计"，无装饰。技术就比较轻松一些，它更强调动画/交互。Vercel 员工，他的组件很好用，也很 vercel。（推荐：★★★★☆）
- [Risingle](https://www.imrising.cn/) — 网站样式很棒，虽然用的别人的模板，但是他用的很棒。是个初出茅庐的程序员。（推荐：★★★☆☆）
- [無名小栈](https://blog.imsyy.top/) — Risingle blog 的模板主人，或许是头像和网站风格不搭，显得没有 Risingle 的舒服。Github 热门项目还不少，一看就是爱折腾的人，就是不爱写 blog，没啥内容。01 年，挺年轻的，独立开发者？不知道经历了什么。（推荐：★★☆☆☆）
- [韩小韩博客](https://www.vvhan.com/) — 网站很棒，内容多，头像也帅，不知道人帅不帅。就是这个错位滑动效果一直让我头疼，这个阻尼效果还写blog专业上了。。。一个插件导入的事情，啥时候他能把这个效果关掉就好了。挺想多看下他内容的，但是这个效果太头晕了。（推荐：★★★☆☆）
- [Anthony Fu](https://antfu.me/) — 很厉害的一个人，好像还很年轻。经常在 b站活跃，开直播（看过）。我记得它几乎毕业就做了很多厉害的事情，vue 系列核心成员，似乎对他来说很轻松的事情。blog 多是英文，生活圈也是大神汇聚，真好。不怎么爱写blog，但相比来说已经算好的了。可以从他这窥探一些 vue "上流社会"（推荐：★★★★☆）
- [enpitsulin 铅笔](https://enpitsulin.xyz/) — 很简洁的blog网站，像 nanda。只不过很久没内容了。他现在的头像一时让我想不起他是谁了，突然发现它过去可爱头像，我想起来这家伙了。（推荐：★★☆☆☆）
- [秋夜灯雨](https://blog.lierhua.top/) — 看名字，就知道是过去的残党了。但是我挺喜欢他的设计的，页面清晰，一股书生气。虽然是老人，但能追溯的过去并不多。（推荐：★★★☆☆）
- [Cali](https://cali.so/) — 设计师，网站设计不错，但是 blog 内容很少。但厉害的是他已经自己开公司了，给别人设计网站，影石 Insta360 是他们设计的。很好的 blog 参考。他的 zolplay 网站跟 nanda 风格很像，不知道谁抄的谁。（推荐：★★★★☆）
- [Huozhi](https://huozhi.im/) — 极简主义者，网站真的极简，但是感觉也不差。内容不多，当你觉得不知道怎么设计blog，或者设计的不好时，看看他。（推荐：★★★☆☆）
- [Cassie Evans's Blog](https://www.cassie.codes/) — 彩色网站，真的很酷。并且还是位女士，真的很少见。GASP、SVG、动画很精美，但是没几篇内容，也算是高级 blog 的一种诅咒。在 Twitter 上也是名人。（推荐：★★★★☆）
- [講評世界](https://blog.moeyua.com/) — 小透明，失踪人口。但 blog 网站样式有种字体的美，不知道怎么说。好像是影视飓风成员。（推荐：★★☆☆☆）
- [季节记忆](https://www.seamory.com/) — 好像是为后端/嵌入式？2025 年初建立的 blog，无 UI 设计。但少有后端人显露 blog，应当勉励的。（推荐：★☆☆☆☆）
- [博客.cn](https://loud-fear-11e.notion.site/eb29a49346a742989582723f950fcf0f?v=4b4f7b7d24274ba7853426c101a149d7) — 好像是 XMind 的内部 blog notion，不确认，但里面的内容确实专业深刻，先收藏一波（推荐：★★★☆☆）
- [KK](https://kaiyi.cool/) — kk 是跟很厉害的人。突然看朋友圈想起他了，发现他是有 blog 的，虽然已经不维护了。但他的 blog 还残留一些好东西，或许对你有帮助。（推荐：★★★☆☆）
- [灯火不休时](https://blog.dhbxs.top/) — 群友，JAVAR，干净blog，让我看到几个人的影子。（推荐：★★★☆☆）
